# Jira for the factory (plain English)

Write what the project needs, one line each.

Project key PP, for the ParimiPractice portal.
Issue types: Story, Bug, Change Request.
Every issue has a risk tier: low, medium or high.
Every issue has a candidate: the build that was tested.
Every issue has evidence: links to runs, reports and approvals.
Statuses in order: Intake, Preview, Gate, INT, UAT, Prod.
A ticket cannot move to Prod without evidence and an approval.
